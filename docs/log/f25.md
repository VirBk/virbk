# F25

Board ledger is a window, not a novel.

Changed: `factory/tools/ledger.mjs` (new), `factory/tools/renderBoard.mjs` prints the window and
where the rest went, `factory/budgets.json` names `context.ledgerRows` and caps `docs/ledger/*.md`,
gate step `Ledger is a window, not a novel`.

Measured:

```
$ node factory/tools/ledger.mjs --check
ledger check failed
  live ledger has 46 rows, window is 12 - run node factory/tools/ledger.mjs rotate

$ node factory/tools/ledger.mjs rotate
moved 34  kept 12
  docs/ledger/2026-09.md
wrote BOARD.md

$ wc -c BOARD.md factory/board.json docs/ledger/2026-09.md
 7391 BOARD.md
10695 factory/board.json
 4952 docs/ledger/2026-09.md
```

Before this lane the Ledger section was the largest part of the file every seat reads, and it only
ever grew. Rotation is a records act between landings, like the size archive in T53: the script
moves rows, it does not summarise them, and nothing is deleted - a dropped row would be a deletion
git shows.

Self-check changed: the check now also fails when an archived row is newer than the oldest live
row, which is what a rotation run from a stale board would leave behind.
