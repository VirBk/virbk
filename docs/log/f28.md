# F28

The seat is launched with the packet.

Changed: `factory/tools/ghaWriter.mjs` builds the prompt from
`node factory/tools/packet.mjs seat <LANE>` and falls back to the envelope only if the packet
fails, printing which one it used and its size. Every recipe in `factory/tools/seat.mjs` names the
packet as the prompt instead of "paste the envelope" or "prefix: AGENTS, BOARD, envelope".

Before this the Action passed the envelope alone as `-p`, and the seat then went and read the
repository through tool calls. F21 was one line of YAML and the meter reported:

```
{"num_turns":9,"usage":{"input_tokens":195138,"output_tokens":2760,"cache_read_input_tokens":167808,"total_tokens":197898}}
```

The packet is the whole reading path in one prompt, ordered so the static part matches on the next
call:

```
$ node factory/tools/packet.mjs cost | head -6
reading path

    11.3 KB  AGENTS.md
     2.0 KB  BOARD (live slice)
    10.1 KB  traps digest
    23.3 KB  seat packet, no envelope

$ node factory/tools/ghaWriter.mjs --self-test
self-test ok
```

The self-test now fails if `ghaWriter.mjs` stops naming `packet.mjs`, so the launch cannot quietly
go back to an envelope and a browse.

Self-check changed: the fallback. A packet that fails to build must not stop a writer, so the
Action still launches on the envelope and says so on the line above the model.
