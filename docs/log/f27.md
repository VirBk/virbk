# F27

A return pastes the command.

Changed: `factory/tools/seatReturn.mjs` (new), `contracts/seat-return.v1.json` (runtime enum is now
the live topology list; `measured` required; `cachedTokens` added), gate step `A return pastes the
command`.

S06 sat open for two sittings because absorbing it needed a check: a session that confirms it
understands still invents, and no command could fail a spoken confirmation. A return contract can.
`verify` must be a command and `measured` must be what it printed; a return whose measured is
`ok` is refused.

The contract had also drifted from the catalog: it named `desktop-deepseek`, which is not a
topology, and omitted `pc-dashscope`, which F3 through F21 actually ran on. A return from the last
two lanes could not have validated against it.

Self-check changed: the runtime list is read from `factory/runtimes.json` at validation time, and
the schema is compared to it, rather than the tool trusting a list typed into the schema once.
