# F30: a rule can be suspended on purpose, with an expiry

## What changed

`factory/tools/experiment.mjs` and `factory/experiments.json`. A row names a landing step it
suspends, the claim it is testing, the hypothesis, the command that decides it, and an expiry of
at most 30 days. While the row is open the gate **still runs that step and still prints what it
found** — it does not fail the landing on it, and the verdict line says how many were suspended.

Two things stop it becoming a permanent hole: an expired open experiment fails the gate through
step 20, and a suspended step that passes anyway is reported as `ok — X01 suspends it and it
passes anyway`, which is the signal the experiment is finished.

Landed inert. `factory/experiments.json` is empty; nothing is suspended. Owner boundaries —
money, credentials, real people's data, destructive acts — are not suspendable here. T66. D-48.

## Measured

```
$ node factory/tools/experiment.mjs --self-test
experiment self-test ok

$ node factory/tools/landingGate.mjs --self-test
landingGate self-test ok

$ node factory/tools/experiment.mjs list
no experiments — the rules are the rules today
```

The gate's self-test proves the decision directly: given four step results, only the unsuspended
failure counts toward the verdict. The experiment self-test proves the expiry — an experiment
past its date stops suspending and starts failing `check`.

Not measured: an end-to-end run of the gate with a real step suspended. The desktop tool policy
refused it twice as a CI bypass, correctly — an agent demonstrating how to make its own CI stop
failing is the pattern that refusal exists for. The property is covered by the unit tests above
instead. A session with the owner present can run it live in a scratch clone.

## Open, and deferred to the owner: D-49

`AGENTS.md` §5 is titled "Boundaries that never move" and mixes two kinds. A session reading it
cites an engineering preference as though it were physics, and this sitting did exactly that —
repeatedly, to the owner's visible frustration. The proposed replacement for the §5 header and
the two groups, verbatim, so the next session does not have to reconstruct it:

> ## 5. Boundaries
>
> Two kinds, and they are not the same kind. The owner's do not move. The rest are this
> factory's current best guess: they hold until evidence replaces them, and
> `factory/tools/experiment.mjs` is how one comes down on purpose — a hypothesis, a measure, an
> expiry — instead of by decree or by a waiver nobody can read later.
>
> **The owner's.**
>
> - Never commit real people, pay, client, or credential data. Fixtures are synthetic.
> - One private remote. No second remote, no sync client, no deployment without the owner's word.
> - Merge, release, deployment, destructive action, and protected-data access are the owner's acts.
> - Every route declares its permission or its authenticated-only status.
> - No envelope opens a gate. Gates live on the board. The owner closes them with a word.
> - API keys live in a seat's environment, never in git, never in a `VITE_` variable.
> - A cloud writer receives a worktree of the envelope holds, not the owner's disk.
> - GitHub write access is not a contributor. Parent `access` is `owner-only`.
>
> **The factory's, and provisional.** Each has paid for itself so far. An experiment may suspend
> the check that enforces one. None of them is a reason to refuse an idea outright.
>
> - (the remaining §5 bullets, unchanged)

`AGENTS.md` is capped at 12 KB and was at 11522 bytes; the split fits in the headroom. The
control-plane session that proposed this is not the one that should land it.

## Self-check

- The gate reads experiments from the archive of the commit under test, like the manifest, so a
  commit carries its own exceptions and cannot inherit one from the working tree.
- A step name with a typo would suspend nothing while reading as though it had. `itemErrors`
  refuses a name no manifest has.
- An experiment closed without pasting what the measure printed is refused.
- Written by the control plane, not a writer seat. D-45 is still owed and is now two lanes old.
