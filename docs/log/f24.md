# F24

The packet: a reading path with a byte budget.

Changed: `factory/tools/packet.mjs` (new), `factory/budgets.json` gains a `context` section,
`AGENTS.md` names the packet as the reading path, `CLAUDE.md` / `.cursorrules` /
`.github/copilot-instructions.md` point at the command, gate step `Reading path under its context
budget`.

The packet prints, in this order: AGENTS, the live board slice (Now, gates, open lanes, holds,
keystones, shelf), the traps digest, then the envelope. Static bytes first so a provider prefix
cache hits; the envelope, which changes every lane, last. Landed lanes and the ledger are not in
it.

Measured:

```
$ node factory/tools/packet.mjs cost
reading path

    11.3 KB  AGENTS.md
     2.0 KB  BOARD (live slice)
    10.1 KB  traps digest
    23.3 KB  seat packet, no envelope
    33.1 KB  control-plane packet

    31.3 KB  AGENTS.md + BOARD.md + traps.yaml read whole
      26 %  cut by the packet, before the envelope

  no envelope issued - idle is success

$ node factory/tools/packet.mjs --self-test
packet self-test ok
```

The board slice is 2.0 KB against a 7.4 KB BOARD.md, and it is the part that grows. The seat cap
is 26 KB, so the packet sits at about ninety per cent of its budget: the next batch of traps has
to be terse or the cap is raised on purpose, by an envelope, not by drift.

`AGENTS.md` was 11244 bytes before this lane and is 11522 after, against a 12288 cap. Five pointer
rows that explained instead of pointing were cut to pay for the new ones.

Self-check changed: the first draft of the AGENTS paragraph pushed the file to 12072 bytes, 216
bytes under cap. The rationale moved to `factory/OPERATING_MODEL.md`, which is not required
reading, and AGENTS kept the command.
