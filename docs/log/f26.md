# F26

Alumni contribute by measurement.

Changed: `factory/tools/alumni.mjs` (new: `scan`, `intakes`, `drop-status`, `checks`,
`provenance`), `factory/lineage.json` (every absorbed portable intake names the law it became in
`absorbedAs`; each alumnus names the script and gate file its drop expects),
`contracts/intake.v1.json` gains the optional field, `factory/tools/intake.mjs` refuses an
absorbed portable row whose law is not in the tree, `factory/drops/README.md` and `factory/COPY.md`
name the commands, gate step `Alumni scan is read-only and emits valid intakes`.

The scan is read-only and stats files rather than reading them: measuring a repository must not
cost what reading it costs.

and this tool has no write path at all: everything leaves through stdout.
