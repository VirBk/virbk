# F42 — The TRAPS parser: last-wins proved, quoted scalars, an explicit refusal honoured (S19)

## What changed

`factory/tools/alumni.mjs` only, three things.

- **Last-wins, proved.** No production change: `splitCheck` already took the last directive on
  a row. The proof is a fixture row plus an assertion. The row is a markdown bullet, T10: its
  prose names an earlier directive, and the row ends with the directive that counts. The
  assertion names the earlier directive when it wins.
- **A quoted scalar is unquoted.** New `unquote` after `collapse`: one matching pair of
  surrounding single or double quotes comes off, and only a matching pair, so an apostrophe
  inside a rule survives. Applied in `parseTrapsYaml` to id, kind, title, rule (or
  charged/cost) and check. A quoted id, kind or title no longer carries its quotes into the
  value.
- **A refusal is honoured.** New `portableOf(kind)`: after collapsing, `machine` is machine,
  `reject` is reject, anything else is portable. `trapsCandidate` reads it. `trapsReport`
  reads `reject` before the floors and holds the row, named by id with reason `kind reject` —
  the same second outcome a row naming no check already takes. No third outcome, and no
  contract field: `reject` is already in the contract's portable enum.

## Self-check — what it found

Drove all three mutations, restored every file, then confirmed the tree is the commit:

    git status --porcelain
    (printed nothing; exit 0)
    git diff --stat
    (printed nothing; exit 0)

Two things the check settled:

- The item-2 assertion had to reach the parser, not only the candidate. A quoted id mints no
  candidate under the quoted name, so candidate-level assertions alone reported "no candidate"
  and never named the value. Parser-level assertions now print `JSON.stringify` of the id,
  kind, title, check and rule, which is what makes mutation 2 name each quoted value.
- The last-wins fixture must be a multi-line markdown bullet. `splitCheck`'s group runs to the
  end of the line and a yaml rule is collapsed to one line, so two directives co-exist only
  across lines. That keeps T10's red separate from T8's and T9's case-sensitivity reds.
