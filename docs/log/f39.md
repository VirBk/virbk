## Correction 1 — the self-test reaches the send, and watch's property replaces its state

**Item 1.** The env and argv are built in one place, `launchSeat(answer, spec, prompt, spawn)`, and
`run` passes it a spawner from `--spawner <module>` (the `seat.mjs census --lister` seam). The cloud
job passes no flag and gets `spawnSync`; the fixture passes a recorder and reads what the child was
handed. The plan test returned at the `--dry-run` exit, so the four lines the send uses were dead to
it. The launch drive now feeds `run --spawner` the fixture's own envelope, and asserts the child's
`OPENAI_BASE_URL` is the answered base, its `OPENAI_API_KEY` the key VALUE the router named, its
`OPENAI_MODEL` the answered id, `-p -` in argv, no argv element carrying the packet, and stdin the
envelope's own bytes.

**Item 2.** The old assertion read the tree (`if (lanes().length)`): a check that cannot pass, because
the gate archives the commit before the lane's envelope is deleted. Rescoped to the property — watch
is idle when nothing is live and `issued F99` when the fixture's envelope is — both directions driven
through the CLI, envelope present and absent.

**Item 3.** The band sentence in Measurements is the re-run's number; the log's own bytes moved it.
