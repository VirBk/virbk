# F45 — the seat path refuses a worktree envelope that is not the one on main

Envelope F45 (S23), correction 1. Base `ab398c3`, branch `writer/F45`. Holds: this file and
`factory/tools/packet.mjs`.

## What the lane found

A correction envelope lands on main, but a seat reads its envelope from its own worktree, which
sits on the lane branch at the issuance commit and still holds the superseded page. `git fetch`
does not touch a working tree: a seat was launched this sitting, read the old envelope, and
worked to it, and nothing in the read path could say so.

## `factory/tools/packet.mjs`

`git hash-object`: `5cb0ea6155a61527b8df6b42deb1e4c5b998fa54` before the self-check mutations
below and the same after every one was restored, and the same blob hash that
`git rev-parse HEAD:factory/tools/packet.mjs` prints. The seat path only: `seatPacket`, `cpPacket`, `checkErrors`,
`landingStepErrors` keep their signatures and reach no git, so gate steps 16 and 17 still run
where there is no repository.

- `gitProbe(root, args)` — one git command; `{out}` or `{reason}`, never a throw.
- `staleEnvelope(root, lane)`, unexported — resolves `refs/remotes/origin/main` in the worktree,
  reads `factory/envelopes/<lane>.md` at that ref, and compares it with the worktree's copy after
  normalising CRLF to LF: `core.autocrlf=true` here, and a line ending is not a page. Verdicts
  `stale`, `skipped`, or `null` when the two agree, no lane was named, or there is no such file.
- The dispatch: `stale` writes nothing to stdout, puts the reason on stderr and exits 3 — the
  launch line pipes into the harness, so an empty stdin is a loud failure rather than a seat
  working to the wrong page. `skipped` emits the packet, then a one-line NOTE on stderr, exit 0.
  `cp` does not compare: a control-plane read is the control plane's own page, taken from main.
- `gitStaleFixture()` / `gitSameFixture()` — real repositories, skipped loudly if git is absent
  (T09). The first: the issuance page in the worktree, the correction at the tracked main ref.
  The second: one commit with that ref at it, the worktree never moved off it — the common
  launch, where the two pages ARE the same bytes.
- `selfTest` — four properties over three trees, one mutation each (D-62).

## Correction 1, item 1 — the equality branch had no fixture that could fail

The stale tree proves the path can say "different". Neither earlier fixture covered the common
case, where the copies MATCH, so forcing the comparison to report a difference left the
self-test, the check and the gate green while every launch in the factory refused with nothing on
stdout. `gitSameFixture()` is that tree. The assertion drives the CLI a person types and not a
helper: exit 0, stdout byte-equal to `render(seatPacket(tree, lane))`, stderr carrying neither
`refusing` nor `NOTE`. Its own passing run, on this worktree, which is the same shape — the F45
page here equals the copy on live main:

```text
$ node factory/tools/packet.mjs seat F45
exit 0, stdout 32045 bytes
stderr: packet seat F45  31.2 KB          (no refusal, no NOTE)
```

Mutation, at the production entry point — `if (same) return null;` to `if (false) return null;`:

That red is item 1's alone: no other property reads the equality branch, and none of the other

## Correction 1, item 2 — the count was not the command's

This file said `70 budgets`; on this tree the command prints `size budget — 72 budgets, bands at
80 per cent`. The count moves with the tree being measured: `docs/log/*.md` is a measured glob
and this lane's own log is one of its matches, so the lane's commit reads one higher than the
base it came from, and the envelope's `71` was read at main, without this file.

each step's output to `<archive>-logs/NN.txt` beside the archive path it prints, and that file

the Windows script path the gate hands it, so no step starts. That is why step 12, plain `test`
and `grep`, fails beside the node steps.
