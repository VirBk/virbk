# F45 — the seat path refuses a worktree envelope that is not the one on main

Envelope F45 (S23). Base `ab398c3`, branch `writer/F45`. Holds: this file and
`factory/tools/packet.mjs`.

## What the lane found

A correction envelope is written to main, but a seat reads its envelope from its own worktree,
which sits on the lane branch at the issuance commit and still holds the superseded page.
`git fetch` does not touch a working tree. A seat was launched this sitting, read the old
envelope, and worked to it, and nothing in the read path could say so.

## `factory/tools/packet.mjs`

`git hash-object`: `521bfe1ea7aa7242957e5355c5ad5348b9a5a26a` before the self-check mutations
and the same after all three were restored.

The seat path only. Nothing moved into the exported builders — `seatPacket`, `cpPacket`,
`checkErrors`, `landingStepErrors` keep their signatures and reach no git, so gate steps 16 and
17 still run where there is no repository.

- `gitProbe(root, args)` — one git command; `{out}` or `{reason}`, never a throw.
- `staleEnvelope(root, lane)`, unexported — resolves `refs/remotes/origin/main` in the worktree,
  reads `factory/envelopes/<lane>.md` at that ref, and compares it with the worktree's copy after
  normalising CRLF to LF. `* text=auto eol=lf` is pinned here but a checkout elsewhere may not
  be, and this machine runs `core.autocrlf=true`: a line ending is not a page, so it is not a
  difference. Verdicts: `stale`, `skipped`, or `null` when the two agree, no lane was named, or
  the worktree holds no such file.
- The dispatch: `stale` writes nothing to stdout, puts the reason on stderr and exits 3 — the
  launch line is a pipe into the harness, so an empty stdin is a loud failure rather than a seat
  working to the wrong page. `skipped` emits the packet, then a one-line NOTE on stderr, exit 0.
  `cp` does not compare: a control-plane read is the control plane's own page, taken from main.
- `gitStaleFixture()` — a real repository whose worktree holds the issuance page while
  `refs/remotes/origin/main` holds the correction. Skipped loudly if git is unavailable (T09).
- `selfTest` — three properties, one per mutation below. Two fixtures, because one tree cannot
  separate "refused" from "could not compare".

## Self-check: three mutations, driven at the production entry point

Each was driven, its red pasted, then restored byte for byte and re-hashed.

1. Drop the refusal from the seat dispatch.

```text
packet self-test failed
  a stale envelope was handed to a seat — the worktree's envelope differs from the copy on
  main and the seat path emitted it anyway (exit 0, 2619 bytes on stdout)
  a refused launch did not say why — stderr did not name the difference: packet seat F00 2.5 KB
```

Item 1's two properties, and item 2's stayed green.

2. Make the unresolvable case refuse — both `skipped` returns changed to `stale`.

```text
packet self-test failed
  a launch was refused for a comparison nobody could make — exit 3 in a tree with no
  repository: packet seat: refusing — refs/remotes/origin/main does not resolve (fatal: not a
  git repository (or any of the parent directories): .git). ...
  the packet's bytes moved — the note path's stdout is not byte-identical to the rendered packet
```

Item 2's property fired and item 1's two did not, so the two items are not read by one
assertion (D-62). The second red is entailed rather than extra coverage: a refusal writes no
bytes at all, so stdout is not the packet. It is not item 1's red — item 1's marks a stale page
handed to a seat, and this lane emitted nothing.

3. Print the note to stdout instead of stderr.

```text
packet self-test failed
  a comparison that could not be made was not noted — no note on stderr naming the ref it could
  not read
  the packet's bytes moved — the note path's stdout is not byte-identical to the rendered packet
```

Both reds are the mutation itself: the note left stderr and entered the bytes.
