# F50 — the entry-point fixture runs where the gate runs

## What changed

`factory/tools/landingGate.mjs` only.

- `fixtureDirs().done()` no longer swallows a failed removal: it calls
  `removeTree()`, which retries, REPORTS a removal it cannot finish and
  returns the reason. A throw there would hide the finding (T79). `rm`
  and `report` are injectable so a fixture can drive that path without
  waiting for the platform.
- `makeTempRepo()` lays out a throwaway git repository under the OS temp
  dir holding a copy of this tool and `experiment.mjs`, then `git init`,
  one commit, `rev-parse HEAD`. It never throws: a repository it cannot
  make comes back as an `error` string. `spawn` is injectable.
- `fixture7(errors, opts)` builds its own repository — the early return
  when there is none was S24's hole — spawns the copy inside it as the
  process a person runs, and asserts on that. A repository that cannot be
  created is a FAILED fixture naming why; it never skips. `opts` reaches
  `makeTempRepo`, so a fixture can inject a refusal here.
- `fixture10` (property 4), `fixture11` (property 5's report clause), and
  `fixture12`: fixture7's OWN failed-repository branch, driven with a
  refusing spawn on its own errors array, asserting the report exists and
  names the reason. It needs no absent git, so it runs where the gate and
  the Action both run; a second fixture on the helper would prove nothing
  (T79).

`[N …]` is the FIXTURE number, so the new tags are `[7 own copy]`,
`[7 cleanup]`, `[10 repo failure]`, `[11 cleanup]`, `[12 f7 consumption]`.

## Self-check

- The wiring mutations were first run in a "fake repo" holding only the
  two tool files, where the self-test's own archive checks red too
  (`archive missing factory/landing-checks.json`), so one property looked
  like several. Re-run from the real checkout, each reds its own lines.
- The new tags were first `[4 repo failure]`, `[5 cleanup]`,
  `[6 own input]`, which collide with fixtures 4, 5 and 6 in a file where
  the number is the fixture. Renumbered.
- The first M7 attempt deleted every line matching the branch's message,
  which also removed fixture12's own `startsWith` predicate and crashed
  with `ReferenceError: line is not defined`. Narrowed to the
  `errors.push(` line, M7 then reds cleanly. `[12 f7 consumption]` is
  unique against the other `[N …]` tags.
- A skip is the thing this lane exists to delete, so `makeTempRepo`'s
  failure is an `error` and `fixture7` FAILS on it.
