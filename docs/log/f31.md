# F31: the packet prefix is byte-stable, and a check proves it

## What changed

`factory/tools/packet.mjs`. Two assertions added to the existing `--self-test`, plus the
four-line helper they share. The diff is additive — `git diff --numstat` reads
`38 0 factory/tools/packet.mjs`, so no existing assertion was replaced. `seatPacket`,
`cpPacket`, `render`, `boardSlice` and `trapsDigest` keep their signatures and their output;
the output bytes are compared below.

- `prefixBytes(parts)` — what `render` produces before the envelope part, or null.
- (a) the envelope part is last, checked for one issued lane and one unissued lane. A `MISSING`
  part is still the envelope part and still last, so an unissued lane is covered.
- (b) the bytes before the envelope part are identical for two different lane ids, and are not
  empty. An empty prefix means the envelope is not last, so the comparison cannot pass
  vacuously — that is what makes (b) a check and not a diary.

Why: T45. The envelope changes every lane, so the bytes before it are the span a provider prefix
cache can hit, and `packet.mjs` says so in its header comment. Nothing failed if the order
changed. Gate step 16 ran this self-test and checked size, ledger leaks and `MISSING` only.

The prefix is asserted stable within a sitting only. The board slice carries `now` and the traps
digest changes when a trap is absorbed; nothing here asserts cross-sitting stability, and no live
state was removed from the board slice to manufacture it.

## Negative proof

`parts.push(...)` for the envelope part was changed to `parts.unshift(...)` in `seatPacket`:
the envelope moved to the front and the check failed.

```
$ node factory/tools/packet.mjs --self-test
packet self-test failed
  seatPacket: the envelope part is not last for F31 — static bytes and the cached prefix are broken up
  seatPacket: the envelope part is not last for F-lane-b-not-issued — static bytes and the cached prefix are broken up
  seatPacket: a lane produced no bytes before the envelope part
rc=1
```

Reverted. `git diff` contains no `unshift` and no deleted line; the returned diff is additive.

## Self-check

Drove the list a reviewer of this lane would be given. Two things changed as a result:

- The lane-id list was built with `f.slice(0, -3)`, which depends on the regex in `envelopes()`
  forty lines away for the extension being exactly three bytes. Replaced with
  `f.replace(/\.md$/, "")`, so the strip names the suffix it strips.
- The "not last" message did not name the lane it was about. It now names the lane, which is
  visible in the negative proof: two lines, one per lane.

Checked and left alone: the check runs when `factory/envelopes/` is empty (both lanes are then
unissued and both still carry a last part); `render` hashes are unchanged for `seat` and `cp`;
`--self-test` prints exactly what it printed before; no new file and no new gate step.
