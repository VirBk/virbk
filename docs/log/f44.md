# F44 — the census counts seats, not the processes one launch spawns (correction 1)

## What changed

`factory/tools/seat.mjs` and this file. The fold the review cleared and the
ancestor walk are untouched, and the two cleared probes still hold: a self-parent
row resolves to one seat without looping, and two independent launches with
interleaved pids stay separate. One change per dictated item.

**Item 1 — the walk never erases a seat.** Pid-reuse churn can leave two counted
rows that are each other's parent; the old walk returned the row itself on a
revisit and, testing `counted` before the walk, folded the two into *each other*
so both vanished — `0 running writer seat(s)` while seats exist. `seatOf` now
collects the traversal path and the first counted ancestor seen; on a revisit it
has found a cycle and the seat is the counted row with the **LOWEST pid in the
cycle**. Deterministic, and no row is erased.

**Item 2 — a torn chain is reported, not silently counted as another seat.** A
counted row whose `ParentProcessId` is in no row cannot be attached to its launch:
the parent exited between the enumeration and the write. The gap cannot be
inferred, so the row is still **counted**, the census names it and the pid it could
not reach, and the summary says how many rows have a broken chain and that the
count may over-report.

**Item 3 — no uncommanded count.** The sentence "Before this change the same
machine printed `3 running writer seat(s)`" is **deleted**. No command produced
that 3. The measured number for this machine is below, with its command.

onto 7000's launch — counted, named with 7001, uncertainty in the summary.

Each new fixture was asked whether it could fail its property, and one first could
not. The torn report was first asserted with `/^\s*7002\s+\S+[^\n]*7001/m`, which
the *seat row itself* satisfies — the rendered row echoes its own ppid
(`7002 7001 ...`) — so the assertion stayed green with the report deleted. It is
now anchored on the report's own words,
`/^\s*7002\s+\S+[^\n]*chain broken[^\n]*7001/m`; mutation B below proves it reds.
