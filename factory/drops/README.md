# Alumni drops

Otto and Virbos are absorbed references, not live children. Each file is a
paste for that product's control plane.

A drop is a check that product's existing gate can run. A drop that only
mints prose, or that grows an over-cap live file, is refused (T24, T52).
The size script fails; it does not split. Archive at 80% is between
landings, never a writer envelope (T53).

Adopt after the WHEN in the file. Do not copy `factory/` onto them. Do not
fork them off this remote. Helping them is a new empty remote on topology
`help-fork` or `help-collab`, not a retrofit. A lesson they pay for later
returns as an intake (`factory/templates/INTAKE.md`). Absorbing is a Grok envelope.

Adoption is measured, not assumed:

```
node factory/tools/alumni.mjs drop-status otto <path to that working copy>
node factory/tools/alumni.mjs scan <path to that working copy>
```

`factory/lineage.json` names, per alumnus, the script and the gate file the
drop expects. Exit 2 is not adopted. A drop nobody measured is a letter.
